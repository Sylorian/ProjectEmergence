## 资产字段命名-初始化规范

#### 对象包包含的必要属性
+ 对象ID ( type-String ) <在注册表内指向对象包>
  + 对象ID格式为 < 场景编码 - 子场景编码 - 组编码 - 对象编码 >
  + 可以通过对象ID检索取用对象的所在层
```csharp
string Room = "01";
string Livingroom = "01";
string Wall = "01";
string Door = "01";

string DoorID = Room + "-" + Livingroom + "-" + Wall + "-" + Door; 
// DoorID = "01-01-01-01"
 ```

+ BoolProps 
  + { Key < IsReady >；Value <true-当前状态可被交互，false-当前状态不可交互> }
  + { Key < IsHighlight >；Value <高亮控制开关> }
  + { Key < IsShow >；Value <是否被渲染> }
  + { Key < IsPlay >；Value <是否循环动画> }
  + { Key < IsAudio>；Value <是否播放音效> }

+ StringProps
  + { Key < Name >；Value <可填字段，对象名> }
  + { Key < Info >；Value <可填字段，对象描述(流程中 - 剧情相关)> }
  + { Key < Clue >；Value <可填字段，对象线索(流程中 - 用处相关)> }
  + { Key < PrivateLabel >；Value <可填字段，对象的自有标签> }
  + { Key < PublicLabel >；Value <可填字段，对象的公共标签> }

+ FloatProps
  + { Key <>；Value <可填字段> }
  + { Key <>；Value <可填字段> }
  + { Key <>；Value <可填字段> }
